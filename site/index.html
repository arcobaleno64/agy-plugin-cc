Claude Code companion · Gemini CLI + Antigravity CLI

Bring a second model into the review loop.

agy-plugin-cc is a Claude Code companion for running Gemini CLI or Antigravity CLI (agy) as a cross-model task delegate and code reviewer, with pragmatic and adversarial review, MCP tools, and background jobs.

Install the plugin View the repository

Independent project. agy-plugin-cc is community-maintained and is not affiliated with, endorsed by, or sponsored by Google LLC or Anthropic.

One deliberate cycle

Delegate, challenge, inspect, continue.

The visual motion is optional. The workflow remains the same when animation is disabled.

  1. 01

    Choose one engine

    Use Gemini CLI when you have supported access, or AGY as the practical path for personal accounts.

  2. 02

    Ask for another view

    Run a pragmatic review, challenge the approach adversarially, or delegate a longer investigation.

  3. 03

    Inspect the evidence

    Claude Code receives findings and job results so you can decide what to accept, reject, or verify.

Start here

Three commands, then choose an engine.

You need Claude Code, Node.js 18 or newer, and one separately installed and authenticated engine. You do not need both engines.

# Add the marketplace
/plugin marketplace add arcobaleno64/agy-plugin-cc

# Install and reload
/plugin install gemini@agy-plugin-cc
/reload-plugins

Representative workflows

Use the loop at the level you need.

Pragmatic review

/gemini:review --wait

Look for concrete defects in the current change.

Adversarial review

/gemini:adversarial-review --wait Focus on the retry logic

Challenge assumptions and focus the critique.

Background delegation

/gemini:rescue --background Investigate the failing tests

Move a longer investigation into a tracked job.

Honest boundaries

A companion, not a security boundary.

Write behavior

Read-only is an intent, not an enforced filesystem boundary. The plugin checks the workspace afterward and reports detected changes.

Data path

The plugin operates no hosted service. The engine CLI you installed sends the assembled prompt to Google under that engine's terms.

MCP scope

MCP annotations describe a conservative worst case. They are hints, not guarantees about engine behavior or every MCP client.
